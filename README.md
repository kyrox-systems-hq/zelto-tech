# Zelto Tech Website

A responsive one-page website for Zelto Tech, configured for Firebase Hosting.

## Brand palette

- Coral: `#ff6f68`
- Ink Black: `#0a1219`
- Ghost White: `#fdf8fe`

## Firebase deployment

1. Set the Firebase project ID in `.firebaserc`.
2. Authenticate with Firebase CLI.
3. Run `firebase deploy --only hosting`.
